# AWX-EE

Custom AWX-EE runtime container

## Daily build
I'm trying to drop a daily AWX-EE runtime container build in here.
See Build reports for the installed packages.

Container is based upon the latest release (not rawhide) of Fedora minimal container runtime from [Quay.io](https://quay.io/repository/fedora/fedora-minimal)

In the container everything is added to run ansible playbooks and using galaxies.
